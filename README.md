# Client Solutions Coach

Everything needed to deploy the Client Solutions Coach Custom GPT on ChatGPT Enterprise.

## Files

- `setup-guide.md` — Step-by-step admin setup instructions
- `gpt-instructions/system-prompt.md` — Paste into the GPT's Instructions field
- `knowledge/` — Templates for loading team knowledge into the GPT
- `team-launch-deck.md` — Slide deck to share with the team on launch day
