# Knowledge Base Files

This folder holds all documents uploaded to the Client Solutions Coach GPT.

## How to Add Knowledge

1. Copy the right template for your content type
2. Fill it out — the more detail, the better the GPT's answers
3. Save with a clear name: `2024-11-pilot-call-greg.md`
4. Send to the GPT admin to upload
5. Let the team know in Slack what you added

## Templates

| What you have | Use this template |
|---|---|
| Call transcript or call notes | `pilot-call-template.md` |
| Article, blog post, or newsletter | `article-summary-template.md` |
| Skill, technique, or framework | `skill-notes-template.md` |

## File Naming Convention

`YYYY-MM-[type]-[short-description].md`

## Tips

- Be specific — vague bullets produce vague answers
- Paste full transcripts when you have them
- Tag your topics so the GPT can connect related content
